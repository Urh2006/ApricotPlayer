# Security Policy

## Supported versions

Security fixes are provided in the newest ApricotPlayer release. Beta users should stay on the newest beta channel build; stable users should stay on the newest stable release.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use [GitHub's private vulnerability reporting page](https://github.com/Urh2006/ApricotPlayer/security/advisories/new) and include:

- the affected ApricotPlayer version;
- clear reproduction steps;
- the expected and actual behavior;
- any relevant diagnostic output with personal data removed.

Reports involving the updater, downloaded files, cookies, local file access, command execution, or privilege boundaries are especially useful. You should receive an initial response as soon as the report has been reviewed.
