# ApricotPlayer 1.0.0 Beta 28

This is a small navigation hotfix.

## Fixed
- Opening channel videos, channel playlists, popular channel videos, or playlist videos from the active player now prepares the normal results screen before loading the collection.
- After playing something from those collection results, Escape from the player returns to that result list instead of dropping back to the main menu.

## Notes
- This build does not change playback resolving, mpv cache settings, queue order, EQ, bass boost, volume handling, or seek timing.
