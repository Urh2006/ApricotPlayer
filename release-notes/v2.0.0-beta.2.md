# What's new in version 2.0.0-beta.2

## Background playback

- With Background playback enabled, Escape leaves the player and keeps playback running, including when a player button has focus. Escape still closes details and exits full screen first.
- Ctrl+PageUp and Ctrl+PageDown work from menus and result lists while playback continues. The current screen's shortcuts, text entry and first-letter navigation keep priority. Ctrl+Space still pauses and resumes playback.
- The explicit Close button stops playback; its label no longer incorrectly advertises Escape when background playback is enabled.

## Spotify fixes

- Fixed a blocked audio buffer after stopping or replacing Spotify playback, which could prevent further playback until restarting ApricotPlayer.
- Fixed stale end-of-track events and pause state during track changes, which could incorrectly announce Playback finished or leave the next/previous track paused.
- A disconnected Spotify session is now discarded so a later playback request can reconnect. Late connection/login results cannot replace a newer session or restore a removed account.
- Switching accounts clears account-specific lists and pending responses, including editable playlists and hidden songs.
- Removing a like or a playlist occurrence no longer skips unread tracks when the next page loads.
- Previous retains Smart Shuffle recommendations in playback history. Playing a recommendation from the queue uses that queue occurrence instead of trying to find it in the original playlist.
- Fixed library folder identification after an unnamed entry, and removed the 300-track cutoff for large albums.
- Direct artist, podcast show and profile links open the supported Spotify lists.

## Known limits

- This remains a beta. The fixes have automated regression coverage; playback with a live Spotify account and NVDA still needs user verification.
- Spotify settings currently apply to all saved accounts. Audiobooks and complete pagination of an artist's discography remain unsupported.
- Restarting a Smart Shuffle recommendation after its playback session has ended can select an original playlist track; seeking to the beginning during active playback preserves the current track.
