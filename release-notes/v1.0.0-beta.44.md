# ApricotPlayer 1.0.0 Beta 44

## New Player Shortcuts
- Added `Ctrl+0` to reset playback speed to the user's default speed setting and pitch back to `1.0x`.
- Added `Ctrl+Home` to jump to the start of the current video or file.
- Added `Ctrl+End` to jump near the end of the current video or file.
- The new actions are available in Settings > Keyboard shortcuts.

## Fixes
- Batch downloads now continue after a single item fails. ApricotPlayer announces the failed item, keeps downloading the rest, and reports the final batch with errors.
- Playlist and channel downloads now tell yt-dlp to skip unavailable entries/fragments instead of stopping the whole collection.
- YouTube download recovery now tries the `web_safari` client after recoverable format/video-unavailable errors, and only then falls back to cookies if the user has them configured.
- Playback stream resolution gets the same conservative YouTube client recovery after normal and format-fallback extraction fail.

## Unchanged
- Normal successful YouTube playback and downloads still use the existing fast path.
- mpv cache and long-video seek settings were reviewed and left unchanged because no safe cache regression was found in this code path.
