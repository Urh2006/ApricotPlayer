# What's new in version 2.0.0-beta.19

- Full screen video now fills the screen instead of remaining in a narrow strip above the player buttons. F11 or Escape returns to the regular player; Tab reveals the controls for keyboard navigation.
- Fixed intermittent black video or a playback error when opening a video on the Mac.
- On Windows, resizing and switching screens no longer leaves old controls painted behind the current view.
- Fixed playback getting stuck at 0:00 when reopening a file that had finished playing.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
