# What's new in version 2.0.0-beta.3

## Fixed

- With Background playback enabled, Escape returns one screen to the list that opened the player and keeps playback running. It restores the source list and its selection, including Spotify playlists, instead of opening the main menu. The Back button follows the same path.
- Fixed Spotify Previous at the first track stopping playback and clearing the upcoming queue. Repeated Previous now restarts the current track without discarding the queue; after a few seconds, Previous still seeks to the beginning as before.
- Fixed Spotify autoplay after a standalone song: the song is used as the recommendation seed. Next and natural completion wait for pending Spotify recommendations or context pages and continue when they arrive, instead of stopping before the queue is ready. Explicitly disabled autoplay remains disabled.
- Pending skips are cancelled by Previous, loading another item, transfer or disconnect, so late recommendations cannot skip a newly selected track.

## Validation

Regression tests cover actual Connect transport handlers, late recommendation responses, repeated Previous, queue preservation, cancelled skips, and one-step return navigation. Live Spotify playback and NVDA speech still require user verification.
