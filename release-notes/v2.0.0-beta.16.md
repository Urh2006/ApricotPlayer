# What's new in version 2.0.0-beta.16

- A Spotify song you select now plays, or ApricotPlayer tells you that it cannot be played. Before, when the selected song failed to start, Spotify skipped it and the song below it in the list played instead. A start interrupted by the network or by Spotify's audio key service is now tried again. Songs that Spotify plays next by itself are still skipped with a message when they are unavailable.
- On the Mac, the Spotify menu shows its shortcuts with Command and Option, the same way as the main menu, for example Command+Option+Shift+Y for Spotify search. These are the keys that work; Control is left to VoiceOver and macOS.
- On the Mac, the Spotify queue shortcut is now Command+Option+Shift+U, because Command+Option+Shift+Q logs you out of macOS immediately. Windows keeps Ctrl+Alt+Shift+Q.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
