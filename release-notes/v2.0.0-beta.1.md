# What's new in version 2.0.0 beta 1

Draft. Not published.

## ApricotPlayer rewritten in Rust

- ApricotPlayer 2 Beta is a complete rewrite of ApricotPlayer 1.0.21 in Rust, with the same screens, keyboard shortcuts, menus, NVDA and JAWS announcements, texts in all 27 languages, and the same playback, search, downloads, podcasts, subscriptions, AudioVault and updates.
- It installs next to ApricotPlayer 1.x and does not change it. On its first start it copies your ApricotPlayer settings, history, favorites, playlists, bookmarks, positions, subscriptions and podcasts into its own data folder (`%APPDATA%\ApricotPlayer2Beta`). Your saved AudioVault login keeps working.

## Installation

- `ApricotPlayer2BetaSetup.exe` installs for the current user without administrator rights, with an optional desktop shortcut and media player registration.
- `ApricotPlayer2Beta.zip` is the portable version.
- The beta updates itself from later 2.0 beta releases.

## Known limits

- This is a beta: please report any difference from ApricotPlayer 1.0.21 as a bug.
