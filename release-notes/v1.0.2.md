# What's new in version 1.0.2

## Direct links from History

- Fixed direct links from non-YouTube websites sometimes opening the player without starting playback after ApricotPlayer was closed and reopened.
- The source page stored in History is now resolved again when its previous HLS or signed media URL cannot be proven safe across restarts.
- Dynamic stream URLs without a verifiable remote expiry remain cached in memory during the current app session, so repeated playback remains fast without carrying stale session URLs into a later session.
- Stream URLs with an explicit remote expiry remain available to the persistent cache until shortly before that expiry, preserving the existing fast path for YouTube, SoundCloud, and similar services.
- Legacy persistent entries without restart-safety information are ignored automatically. The user's History itself is not cleared or rewritten.

## Verification

- Reproduced the original failure against a saved direct-link History item: its cached HLS URL returned HTTP 410 while a fresh extraction of the same source page returned a different playable URL with HTTP 200.
- Added regression coverage for stale dynamic streams, verified remote expiry parameters, safe cache restoration, and restart-safety classification.
- Normal YouTube playback, volume, EQ, seek, downloads, and local media behavior are unchanged.
