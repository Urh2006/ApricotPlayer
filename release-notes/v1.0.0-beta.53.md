# ApricotPlayer 1.0.0 Beta 53

This beta fixes screen-reader access to Customize main menu.

- Every main-menu option is now a real native checkbox that exposes its checked or unchecked state to NVDA and other Windows screen readers.
- Use Up and Down to move between the checkboxes, Home or End to jump to the first or last item, and Space to toggle the focused option.
- Saving still hides only the selected main-menu entries. Their global keyboard shortcuts and Action Finder actions continue to work.
- Settings and Exit remain permanently visible, and resetting the section enables every customizable item again.

Playback, downloads, AudioVault, volume, bass boost, equalizer, and shortcut assignments are unchanged.
