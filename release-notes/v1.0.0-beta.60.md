# ApricotPlayer 1.0.0 Beta 60

This beta restores smooth, predictable held-key control for volume and pitch.

- A single Up or Down press still changes volume by the configured volume step.
- A single Ctrl+Up or Ctrl+Down press still changes pitch by the configured pitch step.
- Holding any of those shortcuts now uses ApricotPlayer's own repeat controller, matching the established seek behavior instead of depending on inconsistent Windows key-repeat delivery.
- Repeating begins after 180 milliseconds and continues every 110 milliseconds while the exact key and required modifiers remain held.
- Native repeat events cannot double the change while the internal hold controller is active.
- Rapid pitch input is accumulated through one serialized worker. This fixes lost pitch steps caused by several worker threads reading the same previous value.
- Closing the player or switching media cancels pending held-key and pitch work, so changes cannot leak into the next item.

The configured step sizes, seek timing, mpv playback path, EQ, volume boost, and audio filters are unchanged. The fix adds no network calls or player-start delay.
