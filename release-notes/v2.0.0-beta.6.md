# What's new in version 2.0.0-beta.6

## New: ApricotPlayer for macOS

- ApricotPlayer now runs natively on Macs with Apple silicon, with the same screens, menus, shortcuts and player as the Windows version, built for VoiceOver.
- The Mac version includes the menu bar item, notifications, start at login, the default player setting, app and yt-dlp updates, and an import of your data from the Windows version.
- Download ApricotPlayer-macos-arm64.dmg (or the zip) and move ApricotPlayer to Applications. The app is not signed by Apple yet, so the first time you open it, choose Open Anyway in System Settings, Privacy & Security.

## New on Windows and macOS

- Spotify: Followed artists in the Spotify menu.
- Spotify: mark songs with Shift+A and Ctrl+A and add the marked songs to a playlist. Songs already in the playlist are skipped.
- Spotify search is now a screen like the YouTube search instead of a separate window.
- Spotify connects again by itself after a lost session.
- Speed and pitch stay as you set them until you close the player.

## Fixed

- Windows: after Alt+Tab, focus returns to the control you were on.
- Translations keep the order of placeholders in the new Spotify texts.

## Known issues

- Spotify Liked songs: smart shuffle does not turn on yet, and opening Liked songs a second time from Library may not start playback. Both are planned for beta 7.
