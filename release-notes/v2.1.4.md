# What's new in version 2.1.4

## Added

- Radio has a new entry, Surprise me, right after All stations. It plays a random station from Radio Browser. Choose Randomize from all stations for any station in the whole catalog, or Randomize from a country, Randomize from a region or Randomize from a genre or tag, then choose the country, region or genre from the list. Only stations that worked at Radio Browser's last check are chosen, and the same station is not played twice in a row. Going back from the player returns to Surprise me on the same choice, so Enter plays the next surprise right away. A surprise station is added to Recently played, so you can find it again and add it to your favorites. Your Radio filters for all lists, such as the minimum bit rate, still apply.

## Changed

- The context menu of a Spotify playlist has one subscription command instead of two. It says Subscribe to playlist changes when the playlist is not subscribed and Unsubscribe from playlist changes when it is. Both commands appear only if the subscription state cannot be read. Ctrl+Alt+Shift+S and Ctrl+Alt+Shift+F7 work as before.

These changes apply to Windows and macOS. Existing settings and saved data are retained.

Download **ApricotPlayerSetup.exe** or **ApricotPlayer.zip** for Windows, or **ApricotPlayer-macOS-arm64.dmg** for Apple silicon Macs running macOS 26 or later. The Mac ZIP is used by the in-app updater.

The Mac app is not notarized by Apple. If macOS blocks its first launch, open **System Settings > Privacy & Security**, choose **Open Anyway** for ApricotPlayer, and confirm. Use packages from this project's Releases page.
