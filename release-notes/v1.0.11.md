# What's new in version 1.0.11

## Direct MPV Native Engine File Export in Edit Mode

- Changed: Switched Edit Mode file export to directly use MPV's native rendering engine (--pitch, --audio-pitch-correction=yes, --speed, and live equalizer), guaranteeing 100% bit-for-bit identical acoustic results between live playback and exported files.
- Added: Automatic fallback to FFmpeg when MPV is unavailable.

## Verification

- Verified exact MPV audio export across MP3, M4A, FLAC, WAV, and video containers.
- Added unit tests for local_edit_mpv_args and export pipelines.
- Passed full test suite and compile checks.
