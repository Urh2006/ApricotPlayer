# ApricotPlayer 1.0.0 Beta 35

This hotfix fixes a YouTube download failure that can appear while using a VPN.

## Fix
- ApricotPlayer still tries downloads anonymously first.
- Cookies are still used only when YouTube requests authentication.
- If the authenticated attempt cannot see media formats because YouTube requires JavaScript challenge solving, Apricot retries that failed attempt with the bundled Node and yt-dlp EJS solver.

Successful downloads do not receive an extra request or delay. Download quality, FFmpeg processing, fragment settings, and the 250 ms startup timing are unchanged.
