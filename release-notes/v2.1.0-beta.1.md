# What's new in version 2.1.0-beta.1

**This is one of the biggest updates ApricotPlayer has had, and this beta is highly experimental.** Many parts of the program are new and have not been tested widely yet. If you rely on ApricotPlayer every day, do not update now: stay on 2.0.3 until 2.1 is released as a stable version. If you do try the beta, please report what does not work.

The beta is offered through the Beta update channel. Your settings and saved data are kept, and the shortcuts you already use stay the same. Every new command has its own shortcut, which you can change in Settings, Keyboard shortcuts. The keys below are the Windows defaults; the Mac version has the same commands, and Settings, Keyboard shortcuts shows their Mac keys.

## Added

### Sound

- Advanced in the equalizer (F4) sets the frequency and width of every band and adds low and high shelves. You hear changes at once; Save keeps them and Cancel restores the previous sound.
- Audio processing (F5 in the player, or Settings, Playback): balance, mono, dynamic normalization with a limiter, silence removal, headphone spatialization with a SOFA file, and more. Alt+Shift+Left and Right move the balance and Alt+Shift+V tells you where it is.
- Playback transitions (player context menu or Settings, Playback): crossfade between tracks, off by default, 3 seconds when enabled and up to 30 seconds. Crossfade on Previous and Next is a separate option. Fades on seek, pause, start and end of a file are optional too. A list can also start again from the first item after the last one.

### Timers, excerpts and navigation

- Sleep timer in the main menu and on Ctrl+Alt+T: stop after a set time, at the end of the track or at the end of the chapter. It pauses by default and keeps your position, can fade out, warns a minute before it finishes, and counts real time or only playing time. Alt+Shift+T tells the remaining time and Ctrl+Alt+Shift+T cancels it.
- Alt+L repeats the excerpt marked with [ and ], and seeking stays inside it while it repeats. Alt+B opens Marked excerpts, with exact times in milliseconds, saving an excerpt in Bookmarks and exporting one or all excerpts, with the original sound or with your current audio settings. Alt+Shift+PageUp and PageDown play the previous or next excerpt.
- Ten quick positions per file: Alt+Shift+1 to 0 sets one and Alt+1 to 0 jumps to it.
- Ctrl+G goes to a track number, Ctrl+Alt+PageUp and PageDown go to the first and last track, and Alt+Shift+I tells the track number, total, played and remaining time. Alt+T, Alt+R, Alt+D, Alt+Shift+P, Alt+N and Alt+I tell the elapsed and remaining time, the duration, the percentage, the title and the artist. Ctrl+T goes to a time and Alt+P to a percentage.

### Audio tracks, subtitles and audiobooks

- Alt+A chooses the audio track of a video, and Alt+PageUp and Alt+PageDown switch between tracks.
- Alt+S chooses subtitles and can read them aloud. Alt+Shift+S loads a subtitle file and Ctrl+Alt+Shift+F8 loads subtitles from a web address.
- M4B files with chapters open in audiobook mode, and Alt+K switches it on or off for any file. In this mode the chapter keys and the time announcements work within the current chapter, while your saved position and bookmarks still cover the whole book. Alt+Shift+C stops at the end of the chapter.

### Playlists and files

- The playlist editor (Alt+E on a playlist) adds files, links and folders, imports M3U, M3U8, PLS, XSPF, ASX and CUE, exports M3U8, M3U and JSON, and marks, moves and removes entries. Changes are written only when you save. A folder can stay live, so the playlist always plays what the folder contains.
- Ctrl+Alt+Shift+F2 saves the current playing list as a new playlist.
- In a folder list, Delete moves the selected file to the Recycle Bin or Trash, and Shift+Delete deletes it permanently after you confirm. Alt+Shift+M opens Manage files, which copies, moves and deletes several files at once and asks what to do when a file with the same name already exists.

### Radio, IPTV and recording

- Radio (Ctrl+Alt+Shift+1): search stations, browse by country, language, tag and more, keep favorites and recently played stations, vote, and open a station's website. The new artist and title are announced automatically, and Alt+Shift+N repeats them.
- IPTV (Ctrl+Alt+Shift+2): M3U playlists from a file or address, Xtream and Stalker logins, live TV, films and series with episodes, and the programme guide. Channels say what is on now, and Alt+Shift+N tells the current and next programme. Logins are stored protected, and channels with a login in their address are kept out of your history.
- Recording (Ctrl+Alt+Shift+3): record microphones, the computer's sound, single applications or everything except one application, with a volume for each source. Ctrl+Alt+F9 starts, Ctrl+Alt+F10 pauses and Ctrl+Alt+F11 stops, and Ctrl+Alt+Shift+F10 opens the recordings folder. Recordings are saved as FLAC by default.

### Converter and YouTube

- The converter converts to MKA and OGA as well. Converter options (Ctrl+Alt+Shift+K or Settings, Downloads) set the bit rate and quality of each format, the sample rate and channels, how many files of a folder convert at once and where a converted folder goes. Conversion can be cancelled with the Cancel button or Ctrl+Alt+Shift+X, and every file that failed is listed with its reason.
- Ctrl+Shift+Down in the search field shows YouTube search suggestions.
- A link to a video inside a playlist asks whether you want only the video or the whole playlist.
- Alt+Shift+D downloads with options: audio or video, format, quality, maximum height and folder for that one download.

### Media keys and Spotify

- Media keys and the system media controls (the Windows media overlay, Now Playing on the Mac) play, pause, skip and seek while the player is open. You can switch this off in Media controls (Ctrl+Alt+Shift+4 or Settings, General).
- Spotify playlist subscriptions (Ctrl+Alt+Shift+B): follow playlists by other people and hear what changed. By default only added songs are reported; removed songs and order changes can be switched on for each playlist. Checks run every hour by default for the selected Spotify account, and Check now runs one immediately.

### Backups

- Export settings (Ctrl+Alt+Shift+F6) and Import settings (Ctrl+Alt+Shift+F5) save and restore all your settings. Importing asks first and keeps a copy of the replaced settings.
- Export bookmarks (Ctrl+Alt+Shift+F4) and Import bookmarks (Ctrl+Alt+Shift+F3). An import adds the new bookmarks to yours and skips the ones you already have; Replace all my bookmarks is a separate choice that asks first and keeps a copy.
- The four commands are also in Settings, General.

## Changed

- The equalizer has 15 bands instead of 10. Your existing profiles sound exactly as before, because the five new bands start flat. Built-in presets can now be edited, and Reset this preset brings back the original values.
- Settings, Keyboard shortcuts groups every command in categories, searches all shortcuts and gives each command a primary and an alternate shortcut. A new command never takes a shortcut you already use for something else; it stays unassigned instead.
- The main menu has new entries for Radio, IPTV, Recording and the Sleep timer. The playlist context menu ends with Edit playlist.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway. Download only the official release files.
