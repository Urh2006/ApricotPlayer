# ApricotPlayer 1.0.0 Beta 34

This hotfix restores the conservative YouTube cookie behavior used by v0.9.20 and earlier builds.

## Fix
- Downloads first try without cookies.
- ApricotPlayer uses the configured cookie file only if YouTube reports a sign-in or authentication error.
- Cookie auto-refresh remains available if the selected cookies are no longer accepted.

The faster 250 ms download start, persistent Documents cookie source, automatic source refresh, and stream-cache invalidation from Beta 33 remain unchanged.
