# What's new in version 2.0.0-beta.15

- Fixed in-app updates on Windows that could fail and leave the previous version installed. A yt-dlp helper that kept running after ApricotPlayer was closed blocked the installer. ApricotPlayer now stops it when it exits, and the installer closes any leftover helper itself.

If an update to this version fails anyway, end yt-dlp in Task Manager or restart your computer, then update again.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
