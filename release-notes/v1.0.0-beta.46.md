# ApricotPlayer 1.0.0 Beta 46

This beta improves repository hygiene and two library views without changing playback, audio processing, EQ, caching, or downloads.

## Fixed
- Saved YouTube subscriptions and saved RSS/podcast feeds are now stored and shown in alphabetical title order.
- The release and security workflows use current, SHA-pinned GitHub Actions releases.

## Maintenance
- Removed unused legacy source, reverse-engineering output, and one-off refactor utilities from the tracked project.
- Local extraction, recovery, diagnostic, and old-release artifacts are now ignored so they cannot accidentally enter a future release commit.

## Verification
- Added ordering regression tests and ran the complete regression/security suite, dependency audit, critical Ruff check, source startup check, and a release build.
