# ApricotPlayer 1.0.0 Beta 27

This beta closes the remaining 1.0 roadmap items around deeper session restore and release-channel polish.

## New
- Resume last playback session now restores the active player sequence when one was saved.
- Next/Previous after resume keeps the same context for saved folder, playlist, queue, or explicit player sequences instead of falling back to empty or stale result data.
- Diagnostic reports now include the saved last-session sequence count.

## Changed
- Update-channel defaults now depend on build type: beta builds default to beta, future stable builds default to stable.
- Existing pre-release users who somehow have stable stored are still migrated back to beta while running a beta build, so beta updates continue to appear.

## Notes
- The installer fix that deletes the old `{app}\_internal` folder before install is preserved and was not changed in this beta.
- This build does not change YouTube resolving, mpv cache settings, EQ, bass boost, volume boost, or seek timing.
