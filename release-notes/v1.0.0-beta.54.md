# ApricotPlayer 1.0.0 Beta 54

This beta keeps important update notifications visible.

- Application update has been removed from Customize main menu.
- Whenever an update is available, its action is always shown at the top of the main menu, even if an earlier beta saved it as hidden.
- Current downloads, playback queue, resume, and other normal menu actions remain customizable.

The native accessible checkboxes introduced in Beta 53 are unchanged.
