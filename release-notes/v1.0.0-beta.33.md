# ApricotPlayer 1.0.0 Beta 33

This beta focuses on the remaining download-speed and cookie-source reports.

## Fixes
- YouTube downloads use valid configured login cookies on the first attempt instead of repeating the request after an anonymous failure.
- Single audio and video downloads begin after 250 ms instead of 900 ms.
- Existing users whose setting points only to the internal AppData cookie copy are automatically reconnected to a valid `cookies.txt` in Documents or OneDrive Documents.
- Changes to the original cookie file refresh ApricotPlayer's normalized copy and invalidate stream URLs resolved with older cookies.
- Selecting a cookie file now announces and displays the original source path.

## Comparison
The full download implementation was compared method-by-method with v0.9.20, and the packaged components were compared with the v0.9.22 portable build. yt-dlp, FFmpeg, mpv, Python, download formats, conversion quality, and metadata behavior are unchanged.
