# What's new in version 2.0.0-beta.7

## Fixed on macOS

- Holding Command with the pitch or speed shortcut no longer keeps changing pitch or speed after you release the key.
- YouTube search is about four seconds faster. The app now uses the unpacked build of yt-dlp, and yt-dlp updates on the Mac install that build too.

## Spotify login on macOS

- If Safari says the connection is not secure after Continue to the app, choose Visit Website. The address is your own computer, where ApricotPlayer waits for the login.

## Known issues

- Spotify Liked songs: smart shuffle does not turn on yet, and opening Liked songs a second time from Library may not start playback. Both are planned for the next beta.
