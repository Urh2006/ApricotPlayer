# ApricotPlayer 1.0.0 Beta 58

This beta fixes the native Windows crashes that could appear immediately after an uncached AudioVault episode started playing or finished downloading.

- AudioVault preparation, download, and extraction no longer create and destroy a separate native progress dialog. Progress is reported in ApricotPlayer's existing status area instead, avoiding the wxPython/accessibility crash while keeping the percentage visible to screen readers.
- Playing an uncached episode downloads and extracts only that episode into a temporary playback cache. It is reused on later plays and is not treated as a permanent user download.
- The on-demand AudioVault episode cache now follows the configured playback-cache size and removes the least recently used inactive episodes when necessary.
- Use Download audio to keep a permanent copy. ApricotPlayer saves it under the configured download folder in `AudioVault/<show name>` and announces the full destination path when the copy is ready.
- Complete-show caches and active playback files are protected from the on-demand episode cache cleanup.

The original playback crash, a second manual-download crash, and the stable cached control path were reproduced through the real Windows interface. Beta 58 adds focused regression coverage and is verified again as a frozen Windows build.
