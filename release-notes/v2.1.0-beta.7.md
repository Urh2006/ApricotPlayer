# What's new in version 2.1.0-beta.7

**2.1 is one of the biggest updates ApricotPlayer has had, and its betas are highly experimental.** If you rely on ApricotPlayer every day, stay on 2.0.3 until 2.1 is released as a stable version. This beta fixes what was found while testing beta 6. Everything from the earlier 2.1 betas is still included.

## Changed

- The button that runs the chosen action in Spotify subscriptions, Manage files and the playlist editor is now called Run instead of Do it.

## Fixed

- Resume last session right after starting ApricotPlayer with a Spotify song no longer says that Spotify is not connected. It waits until Spotify is connected and then plays. Starting something else meanwhile cancels the wait.
- Volume, speed, pitch and other sound settings changed while paused now apply from the first moment after you press Play, instead of the old setting playing for a fraction of a second first.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway. Download only the official release files.
