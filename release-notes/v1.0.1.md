# What's new in version 1.0.1

## Custom speed and pitch hold timing

- Added two native numeric controls under Settings > Playback: Speed and pitch hold delay and Speed and pitch hold repeat interval. Both values are measured in milliseconds and work with screen readers and keyboard navigation.
- The delay controls how long a key must be held before repetition starts. The interval controls how quickly changes continue after that.
- The defaults remain the balanced 1.0 behavior: 180 ms initial delay and 110 ms repeat interval.
- To reproduce the faster Beta 61 behavior exactly, set the delay to 90 ms and the interval to 45 ms.
- The available safe ranges are 50-1000 ms for the delay and 20-500 ms for the interval.
- The selected timing applies to held `S`, `D`, `Ctrl+Up`, and `Ctrl+Down`. A short press still changes exactly one configured speed or pitch step.
- Volume, continuous seek, playback startup, EQ, bass boost, clipping protection, and audio quality are unchanged.
- Diagnostic reports now include both timing values so tester configurations are easier to compare.

## Verification

- Added regression coverage for default timing, the exact Beta 61 profile, safe bounds, settings registration, and localization.
- The complete automated suite, source compilation, critical Ruff checks, and release-package validation pass for this release.
