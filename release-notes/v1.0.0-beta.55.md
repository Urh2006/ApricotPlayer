# ApricotPlayer 1.0.0 Beta 55

This beta expands SoundCloud search, improves AudioVault navigation, and brings YouTube Shorts into the normal results workflow.

- SoundCloud can now search for tracks, playlists, or artists. Playlists and artist track pages use the same accessible result navigation and dynamic loading as the rest of ApricotPlayer.
- The main menu now says `AudioVault`. Opening it shows Search, recently added TV shows, and recently added movies.
- Fixed AudioVault TV-show searches doing nothing after Enter because their results could not be rendered.
- AudioVault now returns step by step from episode lists and playback to the correct search or recent-results screen.
- YouTube search results and channel video lists include Shorts alongside ordinary videos. Shorts in playlists continue to play as normal items.
- The existing playback, seek, volume, bass boost, clipping protection, and equalizer paths were not changed.

Verified with the full automated test suite, critical static checks, live SoundCloud and AudioVault data, YouTube channel and Shorts extraction, and keyboard-focused wx interface smoke tests.
