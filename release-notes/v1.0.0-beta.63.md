# What's new in version 1.0.0 Beta 63

This beta restores fast YouTube search results and refines the new BPM and volume controls.

- Standard YouTube results no longer wait for the optional Shorts request. If YouTube's Shorts endpoint is slow or retrying, the normal results still appear as soon as they are ready.
- Shorts remain mixed into results when their parallel request finishes in time, without delaying the primary search.
- Pressing `B` after changing speed or pitch now starts a fresh analysis instead of using the previous cached result.
- The announced BPM reflects current playback speed. A 120 BPM track at `1.25x`, for example, is announced as 150 BPM.
- Volume Up/Down once again uses the native Windows key-repeat behavior from before Beta 60. The newer fast timer is no longer used for volume.
- Pitch keeps its current responsive held-key controller and was not slowed down.
- The BPM analyzer is now loaded lazily only when `B` is pressed, so it adds no work to ordinary searching or playback.
- Release builds now use the project's complete dependency environment, preventing missing-module startup failures in packaged builds.

Verified with live YouTube timing, speed/pitch-aware BPM tests, native volume routing tests, the full automated suite, and release-package checks.
