# What's new in version 2.0.0-beta.26

- B in the player now checks the BPM of Spotify songs, also while paused. It uses the same analysis around the current position and accounts for playback speed, just as with other sources. The analysis does not move playback, change the queue or count as listening history.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
