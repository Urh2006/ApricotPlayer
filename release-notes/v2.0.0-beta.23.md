# What's new in version 2.0.0-beta.23

- Fixed seeking in a Spotify song after pressing Ctrl+PageUp to start it from the beginning. When the song had already played for a while, Ctrl+PageUp only returned to its start, and ApricotPlayer then ignored the song's further seeks and pause changes. The position did not change, the sound moved only after a delay, and further presses started from the wrong place. Seeking now works right away, as it does before Ctrl+PageUp.
- Seeking in a paused Spotify song now changes the position at once, so pressing T reads the new time before playback continues, as with YouTube and other sources.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
