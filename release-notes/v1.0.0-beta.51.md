# ApricotPlayer 1.0.0 Beta 51

This beta improves upload-time metadata in YouTube channels and playlists.

- With a YouTube Data API key configured, ApricotPlayer now retrieves metadata for an entire visible page in one batched request before showing the collection.
- Additional pages request metadata only for newly loaded videos.
- Without an API key, or if the API request fails, the existing background yt-dlp metadata fallback continues to work without blocking the collection screen.

Playback, downloads, AudioVault, volume, bass boost, and equalizer behavior are unchanged.
