# ApricotPlayer 1.0.0 Beta 57

This beta makes AudioVault TV shows substantially faster and keeps AudioVault navigation separate from YouTube result loading.

- Opening a TV show now reads the episode list from the ZIP directory with small, bounded HTTP range requests. It no longer downloads the complete show before displaying its episodes.
- Selecting an uncached episode downloads, verifies, and extracts only that episode. Already cached episodes open immediately.
- Next and previous episode controls continue through the AudioVault episode list and prepare the selected episode on demand.
- Downloading a complete TV show still downloads the full package. A screen-reader-named progress dialog now reports download and extraction progress.
- If an AudioVault server does not support partial ZIP reads, ApricotPlayer falls back to the full-package path and shows the same progress dialog.
- Up and Down, letter navigation, and returning from playback no longer trigger YouTube dynamic loading from an AudioVault result list. This fixes `Unsupported URL: https://www.youtube.com/results?search_query=&sp=`.
- Repeated Enter presses do not start duplicate episode jobs, and leaving a show while it is loading prevents a delayed result from reopening it.

Verified with synthetic range/archive regression tests, the full automated suite, a real wx progress-dialog smoke test, and live AudioVault measurements against a 111.9 MB TV-show package.
