# What's new in version 1.0.0 Beta 65

This beta makes every manual BPM check a fresh measurement.

- Pressing `B` always analyzes the current audio again, even when the item, playback speed, and pitch have not changed.
- Previous BPM estimates and unavailable results are no longer replayed from a cache.
- Pressing `B` again while the same analysis is still running reports that analysis is in progress instead of launching competing FFmpeg processes.
- Playback, seek, pitch, speed, volume, EQ, and normal media startup paths are unchanged.

Verified with a regression test for repeated BPM requests, the tempo and player-shortcut suites, the full automated suite, and release-package checks.
