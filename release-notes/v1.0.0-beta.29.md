# ApricotPlayer 1.0.0 Beta 29

This is a small follow-up navigation hotfix for the beta 28 collection return fix.

## Fixed
- When channel or playlist results are opened from the active player, Apricot now saves the previous search/trending result screen before loading that collection.
- Escape now steps back one screen at a time: player -> channel/playlist results -> original results.

## Notes
- This build does not change playback resolving, mpv cache settings, queue order, EQ, bass boost, volume handling, or seek timing.
