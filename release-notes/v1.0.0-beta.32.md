# ApricotPlayer 1.0.0 Beta 32

This beta fixes download performance, background playlist downloads, and refreshed cookie files.

## Fixed
- Audio-only downloads once again use the proven v0.9.57 yt-dlp settings. The video-specific fragment and HTTP chunk tuning added in Beta 26 could make audio downloads much slower on some systems.
- Playlist, channel, and large queued downloads now show a separate non-blocking progress window. Hide or close that window and keep using ApricotPlayer while the download continues.
- Completing a playlist download closes only its progress window, never ApricotPlayer or the active player.
- Multiple long downloads can share the progress window without one completed task hiding another active task.
- ApricotPlayer remembers the original selected cookies file and automatically re-imports it when that same file is edited or replaced.
- Newly imported YouTube login cookies are recognized immediately.

## Notes
- The video download and FFmpeg pipeline was compared with v0.9.57 and is unchanged.
- This build does not change playback, EQ, volume, seek, queue order, or the installer `_internal` replacement fix.
