# ApricotPlayer 1.0.0 Beta 41

## Fixes
- Videos with a stale saved playback position at 100% now start from the beginning instead of becoming stuck at the end.
- Pressing Play at the end now verifies that mpv actually completed the seek to zero.
- If mpv cannot leave EOF, ApricotPlayer reloads the same item from the beginning without carrying over the stale timestamp.
- An immediate EOF caused by a resume position is detected and recovered automatically.

Valid mid-video resume positions still work. Cookie selection, stream caching, EQ, audio processing, downloads, and normal player startup were not changed.
