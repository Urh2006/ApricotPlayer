# What's new in version 2.0.0-beta.5

## Fixed

- YouTube playback prefers the video's original audio over automatically dubbed or account-default audio, regardless of quality ordering or reopening. Previously cached playback URLs are invalidated so old dubbed selections are not reused.
- Opening another Spotify song after pausing starts it playing immediately, rather than inheriting the old song's pause.
- Spotify Next and Previous start the selected song from a paused track. This also works when Next waits for an autoplay recommendation.
- Restarting or seeking within the same song retains its pause state. Explicitly requested paused loads and Connect transfers retain their requested state.

## Validation

Regression tests reproduced the YouTube language selection, inherited PCM pause, and paused Spotify Next failures before correction. Tests cover original-language selection across playback preferences and reopening, ordinary unlabelled audio, unavailable originals, old cache invalidation, paused Next/Previous, delayed recommendations and explicit paused loads.

- 719 Rust workspace tests passed; 29 environment-dependent tests were skipped by the normal workspace run.
- Separately, all 11 real-libmpv tests and 14 LibreSpot tests plus its documentation test passed.
- A live multilingual YouTube video returned 204 formats; original audio was selected in all three playback preferences.
- All 123 Python tests, critical Ruff checks and Rust Clippy checks passed.

Live Spotify-account playback and NVDA speech require user verification.
