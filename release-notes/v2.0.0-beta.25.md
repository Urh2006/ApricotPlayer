# What's new in version 2.0.0-beta.25

- Saving a whole Spotify playlist or another large selection to Liked Songs now works with both Add new ones and Add all. Spotify accepts at most 50 songs in each library change; ApricotPlayer now splits the selection accordingly and verifies each batch. Removing large selections from Liked Songs is fixed too.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
