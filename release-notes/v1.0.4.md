# What's new in version 1.0.4

## YouTube and Direct Link Playback Fixes

- **Restored YouTube video playback:** Fixed YouTube stream extraction by ensuring the bundled Node.js runtime is discoverable across all installation layouts (`_internal/node`, `vendor/node`, system PATH), allowing yt-dlp to solve JavaScript challenges and extract playable stream formats.
- **Direct link playback from other websites:** When playing direct media URLs (MP3, MP4, M3U8, AAC, web audio/video streams) where yt-dlp's generic webpage extractor fails or returns HTTP 403, ApricotPlayer now falls back directly to mpv streaming.
- **Robust format fallback:** YouTube stream resolution now includes fallback to audio-only and adaptive streams to prevent "Requested format is not available" errors.
- **Updated yt-dlp runtime:** Upgraded the bundled and pinned yt-dlp component to 2026.8.19.
- **Runtime tool resolution:** Standardized executable resolution for Node.js and FFmpeg across source checkouts, installed one-dir apps, and portable ZIP packages.

## Verification

- Tested stream resolution and playback across YouTube videos, SoundCloud, direct MP3 streams, direct MP4 media files, and direct HLS/M3U8 playlists.
- Added regression tests for runtime discovery and direct link fallback.
- Passed all 108 automated tests, bytecode compilation, critical Ruff checks, and clean git diff validation.
