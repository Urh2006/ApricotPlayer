# ApricotPlayer 1.0.0 Beta 38

## Fixes
- Restore to defaults and every per-section settings reset now work again.
- Removed the duplicate Reset all settings button from General; Restore to defaults remains the global reset action.
- Related autoplay avoids YouTube videos already played during the current player session.
- Cookie source details are now included in diagnostic reports for investigating machine-specific refresh problems.

The existing cookies source refresh passed change-and-restart testing. Long-video cache and scrubbing code was not changed because no regression was found.
