# ApricotPlayer 1.0.0 Beta 56

This beta repairs AudioVault keyboard activation and expired login sessions.

- Enter now opens Search, recently added TV shows, and recently added movies directly from the AudioVault submenu.
- Enter on a movie or TV show now uses the AudioVault playback path instead of the generic YouTube results path.
- Fixed the `Unsupported URL: https://direct.audiovault.net/login` playback failure.
- If the AudioVault website session expires, ApricotPlayer signs in again with the saved Windows DPAPI-protected credentials and retries the original catalog, playback, TV-show, or download request once.
- If credentials are not saved, ApricotPlayer shows the login dialog when AudioVault is opened.
- Normal updates do not delete the saved AudioVault login. Logout, changing the saved email, and resetting AudioVault settings still clear it intentionally.
- File and download permission errors remain separate from login errors.

Verified with the full automated test suite, a real wx keyboard-routing smoke test, live AudioVault login and catalog data, direct `audio/mpeg` stream resolution, and a forced expired-session login retry.
