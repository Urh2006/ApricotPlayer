# What's new in version 1.0.0 Beta 64

This beta restores pitch controls to their behavior from Beta 59 and earlier.

- Pitch Up/Down now uses Windows' native key-repeat events again. Every event changes pitch by exactly one configured step.
- The custom 90/45 ms held-key timer introduced after Beta 59 has been removed completely from volume and pitch.
- Rapid pitch requests are no longer combined into a separate batching worker.
- Volume remains on the same native key-repeat path restored in Beta 63.
- Seek controls keep their existing independent hold behavior and were not changed.

Verified with regression tests for direct volume and pitch routing, one pitch worker per native event, the full automated suite, and release-package checks.
