# What's new in version 1.0.0 Beta 62

This beta adds accessible BPM detection directly to the player.

- Press `B` while media is playing to analyze its actual audio and hear the estimated tempo in beats per minute.
- The shortcut is configurable as `Player: announce BPM` under Settings > Keyboard shortcuts.
- It works with YouTube, SoundCloud, podcasts, local files, and AudioVault because it analyzes the current resolved audio stream rather than guessing from titles or metadata.
- ApricotPlayer announces `Analyzing tempo` while the background check runs, then announces the BPM result.
- Speech, silence, non-rhythmic material, and low-confidence results announce `BPM not available` without opening a dialog.
- Results are cached for the current session, and stale analysis is cancelled when the player changes to another item.

The detector uses the bundled FFmpeg and a dependency-free multi-band onset and tempo analysis implementation. It adds no work or delay to ordinary playback unless the BPM shortcut is pressed.
