# What's new in version 1.0.0 Beta 61

This beta makes held volume and pitch adjustment substantially faster and smoother.

- The first configured volume or pitch step still happens immediately when the shortcut is pressed.
- Holding Up or Down for volume now starts continuous repetition after 90 milliseconds instead of 180 milliseconds.
- Holding Ctrl+Up or Ctrl+Down for pitch uses the same faster behavior.
- Continued repetition runs every 45 milliseconds instead of every 110 milliseconds.
- A normal short press still uses the exact volume or pitch step configured in Settings.

The repeat loop remains deliberately bounded so it cannot flood mpv or consume an entire CPU core. Playback startup, seeking, EQ, volume boost, audio filters, and network behavior are unchanged.
