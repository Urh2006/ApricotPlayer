# ApricotPlayer 1.0.0 Beta 43

## Fixes
- Fixed the Beta 42 `Requested format is not available` error on affected YouTube videos.
- The truncated-stream recovery now inspects the formats YouTube actually returns instead of requesting a guessed HLS selector.
- Affected videos use a valid 360p combined HLS stream with the original audio language.
- Normal YouTube videos keep the existing fast playback path with no additional request or startup delay.

The reported video `ezFU3UrbcTI` was reproduced through the cookie fallback path, started from 0:00, and completed a direct seek to 10:00 with the bundled mpv.
