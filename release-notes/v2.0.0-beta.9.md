# What's new in version 2.0.0-beta.9

- Windows and macOS retain the saved audio output when the startup device check fails or is interrupted. A failed check no longer produces a false missing-device prompt or resets the preference to auto. A successful check still handles a genuinely missing device.
- This release's Apple silicon DMG and updater ZIP are built by GitHub Actions from the same clean commit as the Windows installer and portable ZIP.
- The macOS workflow verifies locked workspace tests and Clippy, real libmpv playback, the extracted application's signature and packaged helpers, DMG integrity and exact source provenance. Packaged playback qualification now works on macOS too.

The macOS minimum is derived from the actual bundled executables and libraries and recorded in Info.plist and build-info.json. The package is ad-hoc signed and not notarized. After copying it to Applications, macOS may require a one-time Open Anyway approval in System Settings, Privacy & Security. Download only the official release assets.

Automated CI checks do not certify complete VoiceOver/NVDA speech or physical global shortcut delivery. The account-dependent Spotify Liked Songs reopening issue and Smart Shuffle remain unverified; this release does not claim to fix them. Details: docs/AUDIT_BETA9.md.
