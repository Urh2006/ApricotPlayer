# ApricotPlayer 1.0.0 Beta 47

This beta completes the currently open GitHub issue set with accessible library organization and media metadata navigation.

## Categories
- Assign a category to any saved YouTube subscription or RSS/podcast feed with **Set category**. Typing a new name creates that category; leaving the entry blank removes it.
- Use **Filter by category** to show one group or all items. Categories are retained after refreshing RSS feeds and the selected item keeps focus after sorting.

## Media Fields
- In any media list, use `Ctrl+Alt+Left` and `Ctrl+Alt+Right` to hear individual fields such as title, channel, duration, views, upload date, album, playlist size, or local path.
- Both shortcuts are configurable in Settings > Keyboard shortcuts.

## Existing Features Verified
- Apple Podcasts catalogue browsing by category, YouTube Shorts URLs, main-menu focus restoration, and the updater path are all available in the current build.
- The main menu and Action Finder now say **Search YouTube / SoundCloud**, and the search screen retains its provider selector.

## Verification
- 31 offline regression tests, critical Ruff checks, source compilation, dependency audit, and the GitHub installer/portable build pass for this release.
