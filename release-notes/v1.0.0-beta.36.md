# ApricotPlayer 1.0.0 Beta 36

This beta removes a measured delay before some downloads begin while using a VPN.

## Fix
- Successful anonymous downloads still use the same single fast request.
- When YouTube explicitly requests authentication, ApricotPlayer now combines the cookies and JavaScript challenge-solving retry.
- This removes a redundant failed request that added about two seconds in the reproduced VPN case.

Download formats, quality, FFmpeg processing, fragment settings, and normal non-VPN behavior are unchanged.
