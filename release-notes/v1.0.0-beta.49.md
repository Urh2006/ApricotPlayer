# ApricotPlayer 1.0.0 Beta 49

This hotfix repairs AudioVault playback and cleans up its result list.

- AudioVault movies can locate the bundled internal mpv player across installer, updater, portable, and source layouts.
- Enter on a TV show correctly prepares and opens its episodes.
- AudioVault results no longer announce an irrelevant `Uploaded` field or age.
- This release keeps the established `mpv.exe` player backend. The local libmpv experiment is not part of beta 49.
