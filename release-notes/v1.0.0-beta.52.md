# ApricotPlayer 1.0.0 Beta 52

This beta adds a fully customizable main menu.

- Settings now includes a Customize main menu section containing an accessible checklist of all optional main-menu entries.
- Use Up and Down to select an item and Space to show or hide it, then save the settings.
- Hidden menu items remain available through their global keyboard shortcuts and the Action Finder.
- Settings and Exit are always present and cannot be hidden.
- All entries are enabled by default. Resetting this section or restoring all settings makes every entry visible again when its underlying feature or state is available.
- Conditional entries such as application updates, active downloads, playback queue, and resume last session follow the saved preference when they become available.

Playback, downloads, AudioVault, volume, bass boost, equalizer, and shortcut assignments are unchanged.
