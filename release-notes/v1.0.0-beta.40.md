# ApricotPlayer 1.0.0 Beta 40

## Fixes
- Unrestricted YouTube videos no longer enter the cookie fallback after yt-dlp has already returned playable fallback formats without cookies.
- Cookie loading is deferred until an authentication, age restriction, or JavaScript extraction error actually requires it.
- Age-restricted and sign-in-protected playback continues to use valid YouTube login cookies when needed.

Player caching, seeking, audio processing, and downloads were not changed.
