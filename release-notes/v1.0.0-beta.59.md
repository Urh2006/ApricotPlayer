# ApricotPlayer 1.0.0 Beta 59

This beta makes the existing Ask where to save each download option consistent across every supported online source.

- YouTube and SoundCloud keep their current save-location behavior.
- AudioVault movies and individual episodes now ask for an exact destination when the option is enabled.
- Downloading a complete AudioVault TV show asks for one destination folder and copies every episode into it. When the option is disabled, the show continues to use the configured default download folder.
- Downloading a complete podcast feed now asks for one destination folder and saves all episodes there. Individual podcast episodes already follow the same global setting.
- Cancelling a file or folder selection cancels the download before a background task starts.
- AudioVault dialogs start in the appropriate AudioVault download folder, and choosing an existing folder for a complete show does not delete unrelated files already stored there.

The download and streaming engines are unchanged, so this update does not add network calls or delays to playback or downloads.
