# ApricotPlayer 1.0.0 Beta 42

## Fixes
- Fixed some YouTube videos opening at the total duration, showing zero remaining time, and refusing to restart.
- ApricotPlayer now detects malformed progressive MP4 streams whose real size is far smaller than the size reported by yt-dlp.
- Only affected videos use a valid combined HLS fallback with the original audio language. Normal videos keep the same fast playback path.
- HLS fallback URLs now expire correctly in the stream cache.
- Removed the unrelated Beta 41 resume workaround after confirming that saved playback position was not the cause.

The reported 31:40 video was reproduced directly, started from 0:00 with the new fallback, and remained instantly seekable.
