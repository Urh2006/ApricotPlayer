# ApricotPlayer 1.0.0 Beta 31

This beta fixes a resume-position bug found with local files and background playback.

## Fixed
- Resume positions are now saved for the media item that mpv is actually playing, not whichever item the UI is preparing next.
- Opening another local file while the previous file is still playing in the tray no longer copies the previous file's timestamp onto the new file.
- The same protection also applies to YouTube items, playlists, folders, and podcasts when changing playback without fully closing the player first.

## Notes
- This build does not change playback resolving, mpv cache settings, queue order, EQ, bass boost, volume handling, or seek timing.
