# What's new in version 2.1.7

## Changed

- A Spotify artist now opens as a short list of parts: Popular, All songs, Albums, Singles and EPs, Compilations, Appears on, Playlists and Related artists. Each row says how many entries it has, and parts the artist does not have are left out. Before, the artist page mixed ten popular songs with only the first ten releases of each kind, so it could look as if that was all the artist had made.
- Every part opens as its own complete list. Albums, Singles and EPs and Compilations list the newest release first. Long lists load more entries as you reach their end, as other Spotify lists do. Escape goes back to the same row of the artist page.
- On a row of the artist page, the context menu and the Spotify shortcuts act on the artist, as they do on an artist in search results, so you can play, follow, start a radio or copy the link from there. Open in the context menu opens the selected part, like Enter.
- Releases in Spotify lists now say whether they are a single, an EP, a compilation or an album, for example "FUEGO, single, 2026".

## Added

- All songs lists every song of the artist's albums, singles, EPs and compilations, newest release first and in the order of each release. A song that came out again with the same title and length, for example as a single and later on an album, is listed once, at its newest release. Reading All songs takes one request for every release, about 4 seconds for an artist with 160 releases, so the list is kept until ApricotPlayer closes and opens at once the next time.
- Playing a song from All songs continues with the next song of that list.

These changes apply to Windows and macOS. Existing settings and saved data are retained.

Download **ApricotPlayerSetup.exe** or **ApricotPlayer.zip** for Windows, or **ApricotPlayer-macOS-arm64.dmg** for Apple silicon Macs running macOS 26 or later. The Mac ZIP is used by the in-app updater.

The Mac app is not notarized by Apple. If macOS blocks its first launch, open **System Settings > Privacy & Security**, choose **Open Anyway** for ApricotPlayer, and confirm. Use packages from this project's Releases page.
