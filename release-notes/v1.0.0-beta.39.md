# ApricotPlayer 1.0.0 Beta 39

## Fixes
- Updated external `cookies.txt` files are detected by a SHA-256 content signature, including replacements with the same file size or timestamp.
- Cookie source refresh failures are included in diagnostic reports.
- Chrome no longer waits for a DevTools fallback that Chrome 136 and newer block for default profiles.
- Chrome DPAPI errors now explain the supported alternatives: select an exported Netscape `cookies.txt` file, or use Firefox or Brave.

Playback, media cache, and long-video scrubbing code were not changed.
