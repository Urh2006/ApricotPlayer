# What's new in version 2.0.0-beta.22

- Fixed Spotify songs that would not start with "Spotify playback was interrupted" when skipping quickly through a playlist. Spotify lets an account start about 30 new songs in quick succession and then about one new song every 30 seconds. ApricotPlayer now waits until Spotify allows the song, says once that Spotify is limiting new songs, and then starts the song by itself, so you no longer have to go back and forward again. A song Spotify refused also no longer downloads its whole file in the background, which slowed down the following songs.
- Fixed seeking in Spotify songs. Pressing Right Arrow or Left Arrow quickly now moves the position with every press. A press made before the previous one had taken effect used to start from the old position, so presses were lost and the position jumped unevenly.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
