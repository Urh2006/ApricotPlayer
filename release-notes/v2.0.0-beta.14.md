# What's new in version 2.0.0-beta.14

- While something plays, the window title names it followed by ApricotPlayer, for example "Song name - ApricotPlayer". Spotify songs read "Song by Artist - ApricotPlayer", the same way the Playing announcement names them.
- Escape on a player opened with Resume last playback session now returns to the main menu, where you started it, instead of the list the session was originally played from. The player's Back button is named Back to main menu in this case.
- Typing in the Spotify search field on Windows no longer runs list shortcuts, such as Shift+A for selecting a result, or a custom single-letter shortcut.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
