# What's new in version 2.1.0-beta.3

**2.1 is one of the biggest updates ApricotPlayer has had, and its betas are highly experimental.** If you rely on ApricotPlayer every day, stay on 2.0.3 until 2.1 is released as a stable version. This third beta adds another group of requested features. Everything from the earlier 2.1 betas is still included; their release notes describe those commands and keys.

The keys below are the Windows defaults. On the Mac, Command takes the place of Ctrl and Option the place of Alt; Settings, Keyboard shortcuts shows every key and lets you change it.

## Added

### Playback

- Ctrl+Alt+Up sets the volume to the highest the player allows, and Ctrl+Alt+Down to 5 percent.
- N says the name of what is playing. Press it again quickly to hear the file path or web address, and a third time to copy it.
- Alt+Shift+L opens the list of everything in the playing list with its numbers, size and times; choose one and Play jumps to it.

### Files

- Settings, Playback, "Open a file from the system with": a file you open from File Explorer, Finder or Play file can bring the other files of its folder, or of its folder and subfolders, so Next goes on to the next file. Only that file stays the default.
- Ctrl+Alt+Shift+E lists the recently opened files and folders. Choose one to open it, or clear the list.
- Ctrl+Alt+V opens the file or folder on the clipboard, copied in the file manager or as a path.
- Alt+Shift+F copies the selected or playing file so you can paste it in a folder.
- Shift+F2 renames the selected or playing file. A name without an extension keeps the current one. In Favorites, Shift+F2 renames the favorite.
- Alt+Shift+E shows the file selected in its folder, and Alt+Enter opens its properties.
- While listening, Ctrl+K marks or unmarks the playing file, K tells how many files are marked, and Alt+Shift+K opens Manage files with all of them marked, to copy, move or delete them together.

### YouTube

- Settings, Downloads: keep the video's chapters in downloads, and remove sponsor, self-promotion and reminder segments with SponsorBlock. Both are off unless you switch them on.
- Settings, General, "yt-dlp update channel": Stable, Nightly or Master. Nightly follows YouTube changes sooner; Master is the newest and less reliable.
- Settings, Playback, "A link to a video in a playlist": ask each time, always play only the video, or always open the whole playlist.
- Ctrl+B opens the page of the selected or playing item in the browser, and Alt+Shift+B its channel's page.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway. Download only the official release files.
