# What's new in version 1.0.6

## Smooth Seeking and Buffering Elimination

- Fixed: Eliminated buffering and stalls when seeking forward and backward across YouTube, podcasts, and direct web links by adding active 2-minute readahead pre-buffering.
- Fixed: Prioritized high-speed unthrottled streams (format 18 at 23 MB/s) to ensure fast initial buffering before falling back to alternative formats.
- Changed: Increased back-cache retention in memory and disk so backward seeking is always instant without contacting remote servers.
- Changed: Enabled seekable stream handling for direct HTTP and HTTPS media connections.

## Verification

- Verified throughput and instant seek responsiveness across YouTube, direct MP3s, MP4s, and HLS streams.
- Passed all automated test suites, bytecode compilation, and critical Ruff checks.
