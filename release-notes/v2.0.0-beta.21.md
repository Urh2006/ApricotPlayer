# What's new in version 2.0.0-beta.21

- Fixed Spotify playlists and other Spotify lists staying at Loading. ApricotPlayer keeps a list of the queries Spotify's own web player uses. A week after it last read that list, every Spotify list first read Spotify's web player again, which took a minute or more. The saved list is now used however old it is, and it is read again only when Spotify rejects a query.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
