# What's new in version 2.0.0-beta.20

- Quickly pressing Previous and Next in Spotify no longer makes ApricotPlayer say that a song is not available and skip it. That message came from a temporary failure to get the song's key or data, which ApricotPlayer then treated as if Spotify had blocked the song for the rest of the session.
- If loading a song still fails after a retry, ApricotPlayer now says that Spotify playback was interrupted, and you can play the song again right away. Songs that Spotify really does not allow are handled as before.
- Going back to a song you already played reuses its key instead of asking Spotify again, and moving on while a song is still loading cancels the old attempt, so playback no longer stalls after fast navigation.

The Mac version requires an Apple silicon Mac running macOS 27 or later. After copying ApricotPlayer to Applications, you may need to approve its first launch in System Settings, Privacy & Security, using Open Anyway.
