# ApricotPlayer 1.0.0 Beta 50

This beta makes AudioVault login persistent and improves YouTube upload metadata reliability.

- AudioVault can now sign back in after ApricotPlayer restarts. The saved password is protected with Windows DPAPI for the current Windows account and is never written to settings as plain text.
- The first AudioVault login dialog places focus directly in the email field.
- Logging out, changing the AudioVault email, resetting the AudioVault section, or restoring defaults clears the protected login.
- Channel and playlist upload ages now continue loading for all visible results in small background batches instead of often stopping after the first five.

The initial result list remains immediate; upload metadata is still hydrated in the background.
